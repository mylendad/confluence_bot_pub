# Карта проекта (Project Map)

Этот документ содержит обзор структуры проекта после рефакторинга в соответствии с принципами микросервисной архитектуры.

## Структура директорий

```text
/
├── services/               # Независимые бизнес-сервисы
│   ├── ingestion/          # Сервис сбора данных (Confluence, S2T)
│   ├── rag/                # Сервис поиска и генерации ответов (RAG)
│   └── bot/                # Адаптеры интерфейсов (HTTP API, Bot)
├── shared/                 # Общие модули и компоненты
│   ├── storage/            # Репозитории данных (SQLite, Vector Store)
│   ├── models/             # Общие модели данных (Pydantic)
│   ├── utils/              # Вспомогательные функции
│   └── config/             # Конфигурация системы
├── web/                    # Фронтенд (Web UI)
│   ├── css/                # Стили оформления
│   ├── js/                 # Логика на стороне клиента
│   └── static/             # Статические ресурсы (иконки и т.д.)
├── docs/                   # Документация проекта
│   ├── architecture.md     # Описание архитектуры
│   ├── project_map.md      # Эта карта проекта
│   └── ...                 # Прочие руководства
├── tests/                  # Глобальные интеграционные тесты
├── data/                   # Локальные базы данных и файлы (в .gitignore)
├── .env                    # Настройки окружения (в .gitignore)
└── main.py                 # Точка входа в приложение
```

## Описание компонентов

### Services

*   **Ingestion Service (`services/ingestion`)**: Отвечает за взаимодействие с внешними источниками данных.
    *   `confluence/`: Клиент и парсер страниц Confluence.
    *   `s2t/`: Парсеры Excel/CSV файлов маппинга.
    *   `sync/`: Логика инкрементальной синхронизации и контроля версий.
*   **RAG Service (`services/rag`)**: Мозг системы.
    *   `retriever/`: Логика поиска в векторной базе и классификации интентов.
    *   `llm/`: Адаптер для взаимодействия с GigaChat.
    *   `indexer/`: Создание эмбеддингов и индексация данных.
*   **Bot Service (`services/bot`)**: Интерфейсный уровень.
    *   `http_adapter/`: FastAPI эндпоинты.
    *   `cli_adapter/`: Typer CLI интерфейс.
    *   `sberchat_adapter/`: (Опционально) Интеграция с мессенджерами.

### Shared

*   **Storage (`shared/storage`)**: Уровень доступа к данным.
    *   `sqlite/`: Работа с метаданными витрин и атрибутов.
    *   `vector/`: Работа с JSONL/ChromaDB векторным хранилищем.
*   **Models (`shared/models`)**: Единые контракты данных, используемые всеми сервисами.
*   **Config (`shared/config`)**: Централизованное управление настройками через Pydantic Settings.

### Frontend

*   **Web UI (`web/`)**: Современный одностраничный интерфейс для управления ботом и чата. Разделен на логические слои (HTML/CSS/JS) для удобства поддержки.
